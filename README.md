# cssjs

## 📋 Quản Lý Cuộc Sống (`quan-ly-cuoc-song/index.html`)

Web app một file, giao diện tiếng Việt, dữ liệu lưu ngay trên trình duyệt (không cần server).
Mở file `quan-ly-cuoc-song/index.html` bằng Chrome/Safari trên máy tính hoặc điện thoại là dùng được.

**Các mục:**
- **Tổng quan** – toàn cảnh trong ngày: tiến độ việc, ads, khách mới, khách cọc, đội sale, thói quen, thu chi; kèm **gợi ý việc cho ngày mai** (bấm để đưa vào kế hoạch).
- **Việc của anh** – to-do theo nhóm (Quảng cáo, Đội sale, Bán xe, Cá nhân…), ưu tiên, hạn chót.
- **Quảng cáo** – nhập số liệu mỗi ngày theo kênh (Facebook, TikTok, YouTube, Zalo): chi phí, tin nhắn, lead, SĐT bot thu được, lái thử, cọc, bán; tự tính giá/lead, giá/SĐT, tỉ lệ chốt, biểu đồ 14 ngày.
- **Khách hàng** – lead mới → chăm sóc → đặt cọc → giao xe; nhập hàng loạt bằng cách dán danh sách (Excel, Pancake, Google Sheet); tự chia lead theo lượt; gửi thông tin khách cho sale qua Zalo.
- **Đội sale** – danh sách nhân viên, **chia việc theo lượt** (không đùn đẩy), lịch sử từng việc, gửi/nhắc việc qua Zalo, thống kê việc mở/quá hạn/lead/cọc của từng người.
- **Thu chi**, **Thói quen** (chuỗi ngày), **Mục tiêu & Nhật ký**.

Nút **Sao lưu / Khôi phục** ở cuối trang để tải dữ liệu ra file JSON hoặc chuyển sang máy khác.
